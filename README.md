# Python Exercises

[Leia em português](README.pt-br.md)

Small Python exercises about lists, loops and conditionals, run in the terminal.

## Exercises

| File | What it does |
|------|--------------|
| `01_pares_ou_impares.py` | Shows the even or odd numbers of a list (no repeats, sorted), depending on the user's choice |
| `02_pares_sem_repeticao.py` | Shows the even numbers of a list, without repeats and in ascending order |
| `03_numeros_primos.py` | Shows the prime numbers in a range (10 to 20 by default) |

## How to run

You need Python 3 installed.

```
python 01_pares_ou_impares.py
python 02_pares_sem_repeticao.py
python 03_numeros_primos.py
```

You can also paste any file into [Google Colab](https://colab.research.google.com) and run it there.

## Concepts practiced

Lists, `for` loops, nested loops, `break` and `for ... else`, the modulo operator (`%`), conditionals, `sort()`, and user input with `strip()` and `lower()`.
