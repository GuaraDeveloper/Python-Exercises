# Exercícios de Python

[Read in English](README.md)

Pequenos exercícios de Python sobre listas, laços e condicionais, executados no terminal.

## Exercícios

| Arquivo | O que faz |
|---------|-----------|
| `01_pares_ou_impares.py` | Mostra os números pares ou ímpares de uma lista (sem repetição e em ordem), conforme a escolha do usuário |
| `02_pares_sem_repeticao.py` | Mostra os números pares de uma lista, sem repetição e em ordem crescente |
| `03_numeros_primos.py` | Mostra os números primos em um intervalo (de 10 a 20 por padrão) |

## Como executar

É preciso ter o Python 3 instalado.

```
python 01_pares_ou_impares.py
python 02_pares_sem_repeticao.py
python 03_numeros_primos.py
```

Você também pode colar qualquer arquivo no [Google Colab](https://colab.research.google.com) e executar por lá.

## Conceitos praticados

Listas, laços `for`, laços aninhados, `break` e `for ... else`, o operador de resto (`%`), condicionais, `sort()` e entrada do usuário com `strip()` e `lower()`.
